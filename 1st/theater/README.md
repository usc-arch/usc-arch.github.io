# 創作基礎｜組別清單

中英並列、可直接部署的靜態 SPA，無需安裝套件或建置工具。

## 檔案

- `content.md`：內容主檔；教師順序與原始資料整理於此。
- `index.html`：頁面結構與教師研究連結。
- `styles.css`：版面、配色與響應式設計。
- `app.js`：目錄、目前頁面、全螢幕與鍵盤操作。

## 投影翻頁

- 下一頁：`Page Down`、`↓` 或空白鍵
- 上一頁：`Page Up` 或 `↑`

每次按鍵固定切換一個滿版場景。

## 本機預覽

直接開啟 `index.html` 即可瀏覽。若瀏覽器限制本機功能，可在此資料夾啟動任一靜態網站伺服器。

## 更新原則

以 `content.md` 為內容來源。新增或修改教師資料時，同步更新 `index.html` 對應區塊；不要自行補寫教師未提供的履歷、評價或完整介紹。

## 部署

整個資料夾可直接放入任何靜態網站空間。學校 GitHub repository 的連接與部署設定留待後續處理。
